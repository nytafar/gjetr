# T04 acceptance: Agent name, Sort modes, Cache timers

Date: 2026-09-13. herdr 0.8.2, cache-ttl plugin 0.3.2, Quickshell 0.3.1.

## What landed

- `lib/NamePolicy.js`: Agent name and the workspace › tab Field.
- `lib/SortPolicy.js`: `spaces`, `priority` and `cache` Sort modes, stable,
  plus `sameOrder` so the service keeps its model when a re-sort changes
  nothing.
- `lib/CacheTimerModel.js`: `timers.json` and the plugin's `config.json` to a
  Cache timer with level and label.
- `Service.qml`: `sortMode` (default `spaces`), `sortedAgents`, FileView
  watches on both plugin files, a 1 s display clock that runs only while a
  countdown is visible, and helpers `agentName`, `agentLocation` and
  `cacheTimerFor` for Modules. IPC `state()` now lists `sortMode`, cache
  status and every Card's name, location and Cache timer.

## Decisions forced by the data

**Tab label "renamed" test.** herdr's `TabInfo.number` is an id counter, not
the tab's position, and a new tab is labelled with its 1-based position. In the
live snapshot, tab `w4:tA` has label `"2"` and number `10`. Comparing the label
with `number` would call every default tab renamed. A bare integer label is
treated as the default instead.

**Generic titles.** Claude sets its terminal title to `Claude Code` until a
session has a name. That names the program, not the work, so it falls through
to the tab, workspace and cwd. This covered 2 of 21 live Agents. The list is in
`NamePolicy.GENERIC_TITLES`, and it also skips titles that equal the Agent's
own kind.

**Cache timer format.** Thresholds and levels match the plugin exactly:
critical at `remaining <= crit_at` (300), warn at `<= warn_at` (600), and an
overlay with a mistyped field is dropped whole, as serde does. The label
follows the PRD rather than the plugin: `42m` while ok, `m:ss` in warn and
critical, and `cold` once expired. The plugin itself switches to `m:ss` at
`seconds_threshold` (300) and shows `0m` when expired. `seconds_threshold` is
not read.

**Cold timers in the cache Sort mode.** Live timers come first, with the least
time left first. Expired (`cold`) timers come next, then Agents without a timer.
Ties go to priority, then herdr order. A cold cache cannot be saved any more,
so it ranks below one that can.

| Check | Result |
|---|---|
| Names | 21 Cards. Titles used where specific; `Claude Code` fell back to the workspace label (`inbox`, `obsidian-herdr`) |
| Location | `hvelv › noracle fiken`, `inbox › 7`, `~ › Screen` |

| Watch across atomic replace | Standalone `qs -p` probe: FileView `watchChanges` fired and reloaded after two tmp-file-and-rename replacements (the plugin's write pattern) and one in-place write |

## Not verified

  write the file during a 90 s wait. The probe above covers the same mechanism.
- The cache Sort mode live. There is no way to switch Sort mode until T06; it
  is covered by node tests.
