# T05 acceptance: Agent List Module

Date: 2026-09-13. herdr 0.8.2, Quickshell 0.3.1, Omarchy 4.0.2.

## What landed

- `modules/AgentList/AgentList.qml`: header (Agent count, Sort mode), the
  Offline banner, a GridView of Cards, and an empty state. Presentation only;
  a header tap is emitted as `headerTapped()` for T06 to act on.
- `modules/AgentList/AgentCard.qml`: the Fields its preset selects (status bar
  and status word, kind icon, name, workspace › tab, Cache timer), pressed and
  focused states, and tap to focus.
- `lib/CardPolicy.js`: presets `compact` (status, kind, name, cache) and
  `detailed` (adds location, default); status and cache-level tones as theme
  tokens; kind icon file; touch sizes (56 px minimum, cards 64 and 88 px).
- `lib/LayoutPolicy.js` `columnsFor`: as many columns as keep a Card at least
  440 px wide, up to 3. Portrait fits 1, the landscape panel fits 2.
- `lib/HerdrModel.js` `focusLine`: `pane.focus` with `pane_id`, which is exact.
  `agent.focus` takes a looser `target`.
- `HerdrConnection.qml` `focusPane`: a one-shot Socket per request. A newer tap
  replaces a request still in flight, times out after 3 s, and logs failures
  without touching connection state.
- `Service.qml`: `cardPreset`, `focusAgent`/`focusPane` (known Agents only),
  `kindIconUrl`, IPC `focus(paneId)`, and focus stats in `state()`.

## Theme mapping

Colours are qs.Commons `Color` tokens only, so a theme switch recolours
without code:

| | Token |
|---|---|
| blocked | urgent |
| done | accent |
| working | foreground |
| idle, unknown | muted |
| Cache ok, cold | muted (cold at 0.7 opacity) |
| Cache warn | accent |
| Cache critical | urgent, bold |
| Card fill, pressed, focused | `Style.normalFillFor`, `pressedFillFor`, `selectedFillFor`; focused border accent |

Type follows the Omarchy ramp scaled by 1.25 for the panel, so
`omarchy display text size` still applies. Kind icons are the marks Omarchy's
agents plugin ships, read in place from
`$OMARCHY_PATH/shell/plugins/agents/assets/`. Nothing is copied into the repo,
and a kind without a mark shows its initial.

## Found on the way

**The shell injects `omarchyPath` into services.** `shell.qml` `ensureService`
sets `omarchyPath`, `shell`, `manifest`, `barWidgetRegistry` and
`pluginRegistry` on a new service when the property exists. A `readonly
property string omarchyPath` made that assignment throw. `finalize` then
never registered the service, the next sync created a second one, and the
first came up without `shell`: two gjetr surfaces, the visible one with the
fallback bar inset (top 26 instead of right 28). The property is now writable.
Recorded in `AGENTS.md`.

## Not verified

  not confirmed.

  `TapHandler` uses its default drag threshold.
- The `compact` preset on screen. It is not selectable until T06; node tests
  cover its Fields.
- A light theme, where `codex-light.svg` would be picked.
