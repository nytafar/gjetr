# T03 acceptance: herdr connection, collapsing, Offline

Date: 2026-09-13. herdr 0.8.2, Quickshell 0.3.1.

## What landed

- `lib/HerdrModel.js` (pure, node-tested) holds all protocol knowledge:
  request and subscribe lines, first-line reply parsing, stream line
  classification, snapshot to Agents, event collapsing, reconciliation timing
  and the backoff schedule.
- `HerdrConnection.qml` moves bytes and runs timers. `Service.qml` owns it and
  exposes `agents`, `herdrOnline` and `herdrOffline`. IPC: `state()` and
  `reconnect()` on target `nytafar.gjetr`.
- `DeckSurface.qml` shows a placeholder: the Agent count, greyed out with
  "herdr offline, retrying" while Offline.

## Design forced by what herdr and Quickshell actually do

**Events are not state.** Every new subscriber first gets a paced replay of
recent history (T01 findings, corrected). Folding events into state produced a
phantom Agent against the real herdr (22 Agents where the snapshot had 21). So:

1. Subscribe, wait for `subscription_started`, then take `session.snapshot`.
2. For each event, `HerdrModel.eventInvalidates(model, event)` asks whether it
   would change the rendered Agents. Noise such as `revision`, `scroll`, the
   glyph-prefixed title, plain panes or repeated focus does not.
3. A relevant event schedules a re-snapshot: 250 ms debounce, at most 1 s
   after the first pending change (`reconcileDelay`).
4. Agents are published only when the new snapshot's Agents differ
   (`sameAgents`).

**One Socket per attempt.** A standalone `qs -p` probe showed that a Quickshell
0.3.1 `Socket` reports a failed connect once in its lifetime and then ignores
`connected = true`. It gave no error and made no new attempt, against both a
stale socket file and a missing path. A reused Socket therefore never
reconnects after herdr goes away. That is also latent in omarchy-herdr, which
we lifted from. gjetr creates a new Socket from a `Component` for every
connection attempt and every snapshot request, and ignores signals from
sockets that are no longer current.

## Verified live

| Check | Result |
|---|---|
| Real herdr | `online, 21 agents`; after the replay settled, 21 Agents = 21 agent panes in a fresh `herdr api snapshot`. First 15 s: 189 events, 16 snapshots, 5 publishes; quiet afterwards |
| Collapse (fake herdr, revision noise every 50 ms plus a replayed phantom pane) | 1057 events, 3 snapshots, 2 publishes (initial and one real status flip); phantom never shown; 2 Agents |
| Offline | Fake stopped: `phase: waiting`, `offline: true`, last 2 Agents kept; surface shows greyed count and "herdr offline, retrying" |
| Backoff | Retries logged at 500, 1000, 2000, 4000, 8000, 16000, 30000 ms; steady-state spacing matched to the millisecond. Each attempt fails fast (`socket error 0`) against a stale socket file |
| Reconnect | Fake restarted: next retry went `online, 2 agents`, `attempt` back to 0 |

Only right after a shell restart were the first two retry gaps irregular
(1.7 s, then 0.1 s). QML Timers are driven by the animation clock and catch up
after the event loop has been blocked by plugin loading.

## Development loop

Editing QML or `lib/*.js` of a loaded plugin needs `omarchy-restart-shell`.
`rescanPlugins`, re-linking, and the shell's own plugin reload all restart the
service with the old cached types. `qs ipc -n -p "$OMARCHY_PATH/shell" show`
shows which IPC functions are live, which is a quick check of which build is
running. Recorded in `AGENTS.md`.

## Not verified / deferred

- A real `pane_agent_status_changed`, or a status change in real herdr. Status
  is tracked through `pane_updated` and the snapshot. The fake herdr exercised
  a status flip, but no agent was prompted in the real one.
- `pane_exited` is treated as removing the pane. The snapshot corrects this if
  herdr keeps exited panes around.
- `PaneInfo.title` and a status event's `title` are not projected. NamePolicy
  (T04) takes the name from `terminal_title_stripped`, the tab label, the
  workspace label and the cwd, which the Agent record carries.
- qmllint warnings that remain are tooling-only: `LocalSocketError` and
  `PanelWindow` metadata, `qs.Commons` not importable by qmllint (`Style` and
  `Color`), and the outer `root` id in `Service.qml`'s Variants delegate.
