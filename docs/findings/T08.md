# T08 acceptance: Attention

Date: 2026-09-13. Quickshell 0.3.1, fake herdr (protocol subset) on the panel.

## What landed

- `lib/AttentionModel.js`: Agent lists and taps in, Attention out
  (`blocked` or `done` per pane).
- `Service.qml` updates Attention on every published Agent list, acknowledges
  on every focus request it sends (tap or IPC), and reports `attention` in
  `state()` and on each Card entry. Entering Attention is logged.
- `AgentCard.qml` pulses while in Attention: a 30 % tint and a 3 px border in
  `Color.urgent` (blocked) or `Color.accent` (done), breathing between full
  and 20 % opacity every 1.3 s. The animation runs only while visible.
- IPC `useConfigDir(path)`: reads Config from another absolute directory
  until the shell restarts, so acceptance can point gjetr at a fake herdr
  without touching `~/.config/gjetr`. `""` goes back.

## Rules, and why

| Rule | Why |
|---|---|
| Enter only on a transition of a known Agent | Agents come from snapshots, so a changed status is real. An Agent first seen blocked or done (initial load, a reconnect, a new pane) is not a transition, which keeps the whole list from lighting up on start |
| No Attention while herdr has the Agent focused | That pane is the one on screen. herdr's own `done` means finished and unseen |
| Leave on herdr focus, our tap, or the Agent going away | CONTEXT.md: "has not been focused since". A tap clears at once rather than waiting for the next snapshot |
| blocked → done keeps Attention and changes tone; → working keeps it | Still not focused. The PRD says the pulse lasts until focus |

## Verified live

A throwaway fake herdr served invented data from `/tmp`, and the service read
it through `useConfigDir`. The real herdr and `~/.config/gjetr` were untouched.

| Check | Evidence |
|---|---|
| Initial load | `w3:p2` already `done` on load: no Attention |
| Transition | `w1:p1` working → blocked, `w2:p1` idle → done: `attention {w1:p1: blocked, w2:p1: done}`, journal `attention w1:p1, w2:p1` |
| Pulse | Two `grim -o HDMI-A-2` frames 650 ms apart: faint tint and thin border, then solid urgent and accent fill and border. Clearly visible on black |
| herdr focus clears | Fake `pane_focused` on `w1:p1`: only `w2:p1` left |
| Tap clears | IPC `focus w2:p1` (the tap path): `attention {}` immediately |
| Unrelated change | `w1:p2` idle → working: no Attention |

## Not verified

- A real herdr agent becoming blocked or done. No agent was prompted.
- Tapping a pulsing Card by touch.
