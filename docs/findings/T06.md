# T06 acceptance: Config, Overrides, header cycles Sort mode

Date: 2026-09-13. Quickshell 0.3.1 (Qt 6.11.2).

## What landed

- `lib/vendor/toml.js`: toml.min 1.0.0 (MIT, Weslley Araújo), a
  recursive-descent TOML v1.1.0 parser with no dependencies. Licence and
  local changes are in its header.
- `lib/ConfigModel.js`: `gjetr.toml` and `layouts/<name>.toml` to validated
  Displays, Decks, Layouts and Agent List settings. Each bad value falls back
  to its default with an error naming file and key. A syntax error gives
  `file:line:column: message` and the whole file falls back. Files over 64 KB
  are refused. Output names, Layout names and socket paths are held to
  allowlists, because they later reach paths and `hyprctl`.
- `lib/OverrideModel.js`: `state.json` Overrides keyed per Module
  (`<layout>#<index>`), validated on read, stable serialization. An Override
  equal to the Config value removes itself.
- `tests/support/loadLib.cjs` resolves `.import "x.js" as Name`, so libs that
  import other libs run under node as they do in QML.
- `Service.qml`: watched FileViews for `gjetr.toml` and each Deck Layout,
  loaded blocking so the first frame already has Config. Display name,
  background (`black`, `theme`, `transparent`, hex), socket, card preset, Sort
  mode and focus mode now come from Config and Overrides. It is the single
  writer of `state.json` (atomic FileView writes, nothing written before the
  file has been read). `cycleSortMode()` and `resetOverrides()` are also on IPC
  as `cycleSort` and `resetOverrides`, and `state()` reports Config errors and
  Overrides. Config errors are logged to the journal.
- The header tap calls `cycleSortMode`. The Sort mode label is accent while an
  Override is active and muted otherwise.
- `examples/gjetr/`: commented `gjetr.toml` and `layouts/agents.toml` with
  today's defaults. They were copied to `~/.config/gjetr/`, which did not exist
  before.

## Choices

| Choice | Why |
|---|---|
| Parser: toml.min | MIT and small, and strict. It rejects duplicate keys and unterminated strings, reports line and column, and returns null-prototype tables (no `__proto__` pollution). fast-toml (MIT) was rejected: it writes through `__proto__` and accepts malformed input. smol-toml is BSD-3, not MIT |
| `rotatable` defaults to false | gjetr never rotates an output unless Config opts in (T09) |
| `socket` is top-level | One herdr server per Config for now. Per-Module sockets wait for multi-server |
| Only the first `[[display]]` is used | The service draws one Display; T09 builds Decks across Displays |
| `background = "wallpaper"` is rejected | Not implemented yet (PRD M12) |
| Focus modes `herdr`, `window` | Stored and overridable now; T07 implements `window` |

## Found on the way

The QML engine warns `qt.qml.usedbeforedeclared` for every `const` arrow
function called before its definition. toml.min produced 17 such lines each
time it loaded. The ten affected helpers are now hoisted function declarations.
That was confirmed as 0 warnings in both a standalone `qs -p` probe and the
live shell.

## Verified live

| Check | Evidence |
|---|---|
| Parser in QML | Probe via a `.import` chain: tables, arrays and array-of-tables parse; an error reports `@1:5` |
| Atomic write | Probe: FileView `setText` with `atomicWrites` created the missing directories and wrote `state.json` |
| Config loads | `state()`: `display HDMI-A-2, deck [agents], layout agents portrait`, `errors: []`, one `gjetr` layer, bar inset right 28 |
| Header cycles Sort mode | IPC `cycleSort` (the same function the tap calls): `spaces` → `priority` → `cache` → `spaces`. `state.json` went from missing, to `{"agents#0":{"sort":"priority"}}`, to `cache`, to `{"modules":{}}` when back at the Config default |
| Cache Sort mode | Screenshot: `21m`, `33m`, `48m`, `52m`, `59m`, then `cold`, then Agents without a timer; header `sort cache` in accent |
| Overrides persist | Set to `cache`, `omarchy-restart-shell`: came back `cache`, overridden |
| Reset | IPC `resetOverrides`: `spaces`, `state.json` modules empty |

## Not verified

- **Hot reload of a Config edit in the running service.** Testing it means
  writing the user's Config, which gjetr's rules forbid, so it was not done.
  The same watched-FileView mechanism reloaded across in-place writes and
  atomic renames in the T04 probe. Picking up a Config file created while the
  shell runs is untested (Omarchy's `Color.qml` relies on it).
- **Config errors in the journal from a real bad file**, for the same reason.
  Validation is covered by 21 node tests.
- **The header tap by touch** on the panel. It was exercised through IPC.
